# ¡Boom! 3D · versión web (juego de fans)
Juego de fans sin afiliación con la cadena ni la productora. Plató 3D con equipo rojo contra azul, presentador y concursantes inventados,
voces pregrabadas con Piper (medium/high) y un modo clásico 2D con gráficos y sonidos **redibujados** (no contiene recursos de la app oficial).
